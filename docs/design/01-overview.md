# 1. Overview & Scope

Testset Generator is a self-hostable web application that generates test datasets ("testsets") for LLM-powered applications. Its differentiators (see `docs/GOALS.md` and the white-space analysis in `docs/RESEARCH.md` §1):

- **Realistic human input** seeded from anonymized production data — typos, grammar errors, code-mixing (e.g. Hinglish) with a controlled mixing degree, and domain terminology mined from the user's own corpus (including how users actually mistype it).
- **Multi-turn conversations** generated by a user simulator with configurable behavior dials and a verifier that keeps the simulated user on-goal.
- **SME workflow** — a "Response Spec" that lets business stakeholders declare how responses should look, compiled into generation constraints and exported assertions.
- **Developer workflow** — seed-based expansion, deterministic generation via seeds, exports (JSONL/CSV/DeepEval/Promptfoo), and a programmatic API/SDK/CLI.

## In scope (v1)
- File-upload ingestion + basic anonymization, analysis, single-turn & multi-turn generation, transform (noise) chain, human review/curation, testset versioning, exports, REST API + web UI.
- Fully offline-capable deterministic path (local LLM via gateway for the LLM-dependent steps).

## Out of scope (for now)
- **Evaluation runner** — running testsets against endpoints and scoring. Assertions travel with exported cases for downstream eval tooling; a built-in runner is a possible later addition.
- Full observability/tracing platform; general annotation tooling; multi-tenancy; SSO.

## Design principles
1. **Self-hostable first** — single `docker compose up`; no cloud dependencies required.
2. **LLM-agnostic** — all LLM calls through one gateway abstraction (OpenAI/Anthropic/local via Ollama or vLLM).
3. **Reproducible** — every generation is deterministic given a seed; every case carries provenance.
4. **Library-first** — the core pipeline is an installable Python package; UI/API/CLI are thin shells over it.
5. **Simple by default** — two roles, plain REST, no enterprise machinery until needed.
